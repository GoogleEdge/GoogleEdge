# GoogleEdge

中国大陆的中学生。写代码以 Vibe Coding 为主：自己定需求，让模型起草，再按仓库里的实际实现改到能跑。

主要用 **Python**。也在做大语言模型应用、图像识别和 **YOLO**。

## 公开项目

| 项目 | 做了什么 |
| --- | --- |
| [时鲜 WhatEating](https://github.com/GoogleEdge/WhatEating) | Android 做饭助手。拍照识别冰箱食材，再按天气、时令和口味约束调用 OpenAI Responses API 生成菜谱。Kotlin。 |
| [快门杀 Shoot-Killer](https://github.com/GoogleEdge/Shoot-Killer) | 横屏拍照淘汰。用你自己的视觉模型接口，按 OpenAI Responses 格式比对正脸，对上就淘汰。TypeScript。 |
| [AI 垃圾分类](https://github.com/GoogleEdge/Rubbish_Classify_Python) | 比赛用的 Python 应用，调用智谱大模型做垃圾分类。MIT。 |
| [易析 ExAI](https://github.com/GoogleEdge/ExAI-App) | 规划中的试卷分析应用。Flet + Python，设计为拍照 OCR、ChatGLM 诊断，再用 RAG 给出薄弱点和复习建议。 |
| [Amethyst Yggdrasil](https://github.com/GoogleEdge/Amythest-Yggdrasil) | 给 Amethyst-iOS 加外置 Yggdrasil 登录（LittleSkin 等皮肤站）和一套只作用于启动器界面的 Material 3 风格。Objective-C / Java。 |
| [学生认证](https://github.com/GoogleEdge/blessing_skin_student_check) | Blessing Skin 6.0.2 插件。注册时填写班级、座位和姓名，管理员人工审核；未通过不能改游戏资源，也不能走 Yggdrasil 登录。PHP。 |
| [Vault Rush](https://github.com/GoogleEdge/VaultRush) | 纯 Vibe Coding 的 Minecraft Java 小游戏。红蓝两队抢中央宝库的宝石并送回己方交付点，带职业、战术商店和地图保护。Java 21。 |
| [MCC 聊天转发](https://github.com/GoogleEdge/astrbot_plugin_mcc_transfer) | AstrBot 插件。不调用大模型，用 Minecraft Console Client 把服务器聊天转发到 QQ 群，支持 QQ 官方渠道。Python。 |

更多细节在各仓库的 README 里。
